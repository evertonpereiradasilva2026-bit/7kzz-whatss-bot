# Changelog

## [2.0.0] - 2026-08-16

### Adicionado
- Sistema completo de proteção de grupos
- Anti-link, anti-spam, anti-flood
- Anti-pornô, anti-gore, anti-violência (detecção de texto)
- Anti-fake (detecção de golpes)
- Sistema de palavras bloqueadas personalizadas
- Anti-mídia
- Sistema de advertências (warn/warnings/clearwarn)
- Sistema VIP
- Broadcast para múltiplos grupos
- Comando "oii" com sistema de atualização configurável
- Menus extensos organizados
- Base RPG simples
- Conversor de stickers
- Comandos de administração
- Gerenciamento de grupos

### Recursos
- Bot WhatsApp com Baileys
- Múltiplos grupos registrados
- Comandos de dono
- Sistema de prefixo personalizável
- Nome do bot configurável
- Moderação automática
- Punições personalizáveis (delete/warn/kick)

### Notas
- O WhatsApp não oferece garantia de impedir exclusão de mensagens
- Mensagens de catálogo/produto não podem ser indestrutíveis
- Detecção visual de mídia requer integração com serviço externo
